# Keyboard Shortcuts

## 1. Navigation

| Action | macOS | Windows/Linux |
| --- | --- | --- |
| Search | Click search bar or `/` | Click search bar or `/` |
| Toggle fullscreen | Cmd+F11 | F11 |

## 1. Editing — entering and leaving

| Action | macOS | Windows/Linux |
| --- | --- | --- |
| Enter edit mode | Cmd+E | Ctrl+E |
| Enter edit mode (force raw) | Cmd+Shift+E | Ctrl+Shift+E |
| Toggle visual/raw mode | Cmd+E | Ctrl+E |
| Cancel editing | Escape | Escape |
| Save draft | Cmd+S | Ctrl+S |
| Publish | Cmd+Shift+S | Ctrl+Shift+S |

## 1. Mouse shortcuts

| Action | How |
| --- | --- |
| Edit in raw mode | Shift+click the Edit button |
| Resize image (free) | Drag image handle |
| Resize image (constrained) | Shift+drag image handle |

## 1. Tips

- **Escape** cancels editing without publishing. If you have unsaved changes, your draft is preserved.
- **Cmd+E** is context-sensitive: from view mode it enters edit, from edit mode it toggles visual/raw. Your cursor position is preserved across the switch.
- **Cmd+K** opens the link dialog with a built-in page search. Start typing a page name to see matching results — use arrow keys to navigate and Enter to select.
- **Cmd+Shift+E** is useful when a page has rendering issues in visual mode — it lets you edit the raw markdown directly.
