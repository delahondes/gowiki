# Footnotes

Gowiki supports inline footnotes that appear as superscript numbers with hover tooltips.

## 1. Syntax

```
This is a statement^[with a footnote explaining the source].
```

The content inside `^[...]` supports inline formatting: links, bold, italic, code, and strikethrough.

## 1. Numbering

Footnotes are automatically numbered in document order (1, 2, 3...). The numbers update when footnotes are added, removed, or reordered.

## 1. Footnote section

A "Footnotes" section is automatically rendered at the bottom of the page, listing all footnotes with their full content.

## 1. Editing footnotes

In visual mode, click a footnote number to select it. Use the property panel to edit the footnote text.

In raw mode, edit the `^[...]` syntax directly.
