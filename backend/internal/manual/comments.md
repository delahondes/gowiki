# Comments

Comments allow users to leave notes on pages without modifying the page content.

## 1. Adding a comment

Click the **Comments** button in the action bar to open the comments panel. Type your comment and submit.

## 1. Comment threads

Comments are displayed in chronological order. Each comment shows the author and timestamp.

## 1. Storage

Comments are stored as JSON sidecar files in `data/meta/`, separate from the page content. They do not appear in the page's markdown or version history.
