# Search

## 1. Using search

Type in the search bar at the top of the page. Results appear incrementally as you type.

## 1. Features

- **Full-text** — searches page content, not just titles
- **Typo-tolerant** — finds results even with minor spelling errors
- **Incremental** — results update with each keystroke
- **Ranked** — results are sorted by relevance

## 1. Search scope

Search covers all pages the current user has view permission for. Pages hidden by ACL rules are excluded from results.

## 1. Searching by tag

Type `tag:NAME` in the search bar to list every page bearing that tag instead of running a full-text search. Add a term after the tag to narrow the result set — it is matched as a case-insensitive substring against each tagged page's title or path.

- `tag:sop` — every page tagged `sop`
- `tag:sop biomscope` — pages tagged `sop` whose title or path contains `biomscope`

See [Tags](/wiki/manual/tags) for how to apply tags to pages.
